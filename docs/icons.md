# Menu icons

Local SVG icons from [Lucide](https://lucide.dev/), with original files and complete license notices in `assets/icons`. No external font, CDN or runtime download is needed.

Routes: home / house; units / book-open-text; studio / audio-lines; conversation / messages-square; review / list-checks; settings / sliders-horizontal; dictionary / book-a; account / user-round. Back uses arrow-left.

Icons are decorative SVGs; link labels and accessible names remain intact. Hover and keyboard focus animate gently; reduced-motion preferences disable movement.
